# Panduan File Audio Offline (MP3)

Letakkan file audio materi pelajaran Anda di folder ini (`public/media/audio/`).

### Format yang Disarankan:
- **Format:** `.mp3`, `.m4a`, atau `.wav`
- **Bitrate Rekomendasi:** 128 kbps (suara jernih dan ukuran file hemat untuk offline)

### Daftar Nama File Rekomendasi Sesuai Topik:
1. `informatika.mp3` - Berpikir Komputasional & Algoritma Pencarian
2. `jejak-digital.mp3` - Menjaga Jejak Digital & Keamanan Siber
3. `analisis-data.mp3` - Analisis Data & Visualisasi Grafik
4. `matematika.mp3` - Teorema Pythagoras & Ruang Bangun
5. `ipa.mp3` - Sistem Tata Surya & Gravitasi
6. `ips.mp3` - Interaksi Sosial & Perdagangan Antardaerah
7. `pkn.mp3` - Nilai-Nilai Luhur Pancasila
8. `bahasa-indonesia.mp3` - Teks Laporan Hasil Observasi (LHO)

### Catatan Penggunaan:
- Jika file MP3 diletakkan di sini, pemutar audio akan otomatis menggunakan file MP3 asli Anda secara offline tanpa perlu internet.
- Jika file belum diletakkan, sistem akan menggunakan mode transkrip interaktif dengan simulasi suara otomatis.
