# Panduan Gambar Sampul & Ilustrasi Materi Offline

Letakkan file gambar sampul materi atau diagram pendukung di folder ini (`public/media/images/`).

### Format yang Disarankan:
- **Format:** `.png`, `.jpg`, `.jpeg`, `.webp`, atau `.svg`
- **Rasio Sampul Topik:** 16:9 atau 4:3 (contoh: 800x450 px atau 1200x675 px)

### Daftar Nama File Rekomendasi:
1. `sampul-informatika.png`
2. `sampul-jejak-digital.png`
3. `sampul-analisis-data.png`
4. `sampul-matematika.png`
5. `sampul-ipa.png`
6. `sampul-ips.png`
7. `sampul-pkn.png`
8. `sampul-bahasa-indonesia.png`

### Catatan:
- Jika gambar sampul dimasukkan, thumbnail kartu katalog materi di beranda akan menampilkan gambar asli Anda.
- Jika belum dimasukkan, kartu materi tetap menampilkan ilustrasi kode SVG modern bawaan yang dinamis dan beresolusi tinggi.
