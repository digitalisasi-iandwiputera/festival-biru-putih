# Panduan File Logo Halaman Beranda

Letakkan file 4 logo resmi di folder ini (`public/media/logos/`).

### Urutan dan Nama File Rekomendasi:
1. `logo-kemendikdasmen.png` (atau `.svg` / `.webp`)  
   **Logo 1 (Kiri):** Kementerian Pendidikan Dasar dan Menengah RI
2. `logo-pendidikan-bermutu.png` (atau `.svg` / `.webp`)  
   **Logo 2:** Pendidikan Bermutu untuk Semua
3. `logo-kemendikdasmen-ramah.png` (atau `.svg` / `.webp`)  
   **Logo 3:** Kemendikdasmen Ramah Anak / Inklusif
4. `logo-sobat-smp.png` (atau `.svg` / `.webp`)  
   **Logo 4 (Kanan):** Direktorat SMP / Sobat SMP

### Format & Ukuran yang Disarankan:
- **Format:** PNG dengan latar belakang transparan (transparan/alpha channel) atau SVG vektor.
- **Tinggi Gambar:** 80 px - 160 px (pada tampilan web akan otomatis diskalakan proporsional setinggi judul teks ~36px - 40px agar rapi sejajar).
- **Rasio:** Menyesuaikan logo asli (aspek rasio terkunci, tidak gepeng).

### Catatan Penting:
- Sistem sudah dilengkapi pendeteksi otomatis. Selama Anda belum memasukkan file logo fisik, sistem akan menampilkan lencana placeholder logo yang rapi dan elegan sehingga tampilan web tidak kosong atau rusak.
- Begitu file gambar di atas dimasukkan, logo asli Anda akan langsung muncul menggantikan lencana placeholder secara otomatis.
