# Panduan File Video Offline (MP4)

Letakkan file video ringkasan materi pelajaran Anda di folder ini (`public/media/video/`).

### Format yang Disarankan:
- **Format:** `.mp4` (H.264 / AAC) atau `.webm`
- **Resolusi Rekomendasi:** 720p (1280x720) atau 1080p (1920x1080)
- **Ukuran File Rekomendasi:** 15 MB - 60 MB per topik (agar cepat dibuka siswa dan hemat penyimpanan perangkat sekolah)

### Daftar Nama File Rekomendasi Sesuai Topik:
1. `informatika.mp4` - Berpikir Komputasional & Algoritma Pencarian
2. `jejak-digital.mp4` - Menjaga Jejak Digital & Keamanan Siber
3. `analisis-data.mp4` - Analisis Data & Visualisasi Grafik
4. `matematika.mp4` - Teorema Pythagoras & Ruang Bangun
5. `ipa.mp4` - Sistem Tata Surya & Gravitasi
6. `ips.mp4` - Interaksi Sosial & Perdagangan Antardaerah
7. `pkn.mp4` - Nilai-Nilai Luhur Pancasila
8. `bahasa-indonesia.mp4` - Teks Laporan Hasil Observasi (LHO)

### Catatan Penggunaan:
- Jika file MP4 dimasukkan ke folder ini, pemutar video HTML5 offline akan memutar video Anda dengan fitur Play, Pause, Scrubbing Timeline, Fullscreen, dan Pengatur Kecepatan (1x, 1.25x, 1.5x, 2x).
- Jika file belum dimasukkan, pemutar akan menampilkan mode visual diagram dinamis dengan petunjuk status file.
